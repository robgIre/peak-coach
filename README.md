# Peak — Men's Stamina Coach

A private, no-login, mobile-first web app for men's stamina training. Guided pelvic-floor
workouts plus evidence-informed behavioural techniques (start–stop, squeeze, edging, breathing)
for lasting longer and building ejaculatory control.

**Live:** https://robgire.github.io/peak-coach/

## Features
- **Personalised plan** — short onboarding quiz sets goal, level and frequency
- **Guided session player** — animated orb paces every squeeze/relax and breathing cycle, with a live timer
- **Pelvic-floor program** — Quick Flicks, Long Holds, The Elevator, Endurance Holds, scaled by level
- **Learn** — start–stop, squeeze technique, edging, breathing/anxiety, habit-building
- **Progress** — streaks, 4-week calendar, session stats, milestones
- Everything is stored **locally on the device** (localStorage) — nothing leaves your phone

## Tech
- Single static `index.html` (embedded CSS + JS), zero dependencies, zero backend
- Hosted on GitHub Pages

## Disclaimer
Peak is an educational fitness tool, **not medical advice or treatment**. The techniques are
widely used and evidence-informed, but individual results vary. Persistent concerns about
premature ejaculation, erectile function or sexual health should be discussed with a doctor —
these issues are common and treatable.
